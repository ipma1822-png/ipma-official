IPMA GATEWAY v1.0.0

1) index.html / style.css / script.js / config.js 와 assets 폴더를 함께 업로드합니다.
2) 사진 교체: assets/images 안의 같은 파일명 이미지만 바꾸면 됩니다.
3) 사이트 주소 변경: config.js > links 에서 수정합니다.
4) 회원 카운터: config.js > supabase 의 url, anonKey, table 을 입력하면 REST count를 시도합니다.
5) 현재 경찰무도 링크는 비워두었습니다. 최종 경찰무도 홈페이지 주소를 정한 뒤 config.js에 입력하세요.
6) 음악은 외부 음원을 쓰지 않고, SOUND 버튼을 누르면 매우 약한 브라우저 생성 앰비언트 사운드가 켜집니다.
7) PC/모바일 상단 가로 메뉴, 자동 슬라이드, 좌우 화살표, 모바일 스와이프, 카운터, 3개 사이트 입장 카드가 포함되어 있습니다.
