IPMA 수익사업 1단계 설치 순서

1. 이 ZIP의 전체 파일을 GitHub 경무 저장소에 업로드합니다.
2. Supabase > SQL Editor를 엽니다.
3. admin/SUPABASE-IPMA-REVENUE-PHASE1.sql 전체를 붙여넣고 Run 합니다.
4. 홈페이지 /apply/ 에서 통합회원으로 로그인 후 시험 신청합니다.
5. /admin/revenue-applications.html 에서 본부 관리자 계정으로 접수 상태를 관리합니다.

이번 단계 기능
- 지도자 교육과정 신청
- 지도자 검정·자격증 신청
- 공식 인증도장 신청
- 학생 심사·단증 신청
- 신청자 본인의 진행상태 확인
- 본부의 비용·결제·검토·검정·발급·배송 상태관리
- 자격증·단증 번호 수동 발급

중요
- 현재는 자동결제가 아니라 본부가 입금 확인 상태를 관리합니다.
- 실제 카드·간편결제는 정책과 결제대행사 확정 후 다음 단계에서 연결합니다.
